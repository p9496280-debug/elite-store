# 🔬 NovaLab 3D — Interactive Science & Chemistry Lab

An interactive 3D virtual science laboratory built with **WebGL** and **Three.js**, designed specifically for **Android** and **Amazon Appstore** devices.

## 🌟 Key Features
- **3D Chemistry Laboratory:** Render interactive 3D covalent bonds (H₂O, CH₄ organic molecules).
- **Physics & Quantum Models:** Interactive atomic nuclei and electron shell orbits.
- **Cross-Platform & Lightweight:** Fully responsive and optimized for mobile devices and Amazon Fire Tablets.
- **Touch Controls:** Full 3D camera controls (orbit, zoom, pan) integrated for mobile touch screens.

## 🛠️ Built With
- **Three.js / WebGL** (3D Rendering Engine)
- **HTML5 & CSS3** (Responsive UI/UX)
- **PWABuilder / Android TWA** (Native APK Compilation)
